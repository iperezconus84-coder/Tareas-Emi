# Tareas-Emi
Nos apoyamos como familia y aprendemos juntos.

App web "Agenda de Emilia": entrenamiento diario de rutinas, planner escolar, puntos y tienda de canje.
Publicada con GitHub Pages; los datos se sincronizan con Firebase (Realtime Database + Authentication).
